1. Extraction

Reads the PDF or image (text extraction, with OCR for scans) and asks a local language model, llama3.2:3b running through Ollama, to return the vendor, number, date, amounts and category.

2. Rule checks

Checks the vendor against the approved list, required fields, duplicates, the total, and approval limits. These are plain Python rules, so the same invoice always gets the same answer.

3. Anomaly detection

Compares the amount with past invoices in the same category, using a statistical check and an Isolation Forest model. An unusual amount is flagged for review. It is not called fraud.

4. Report

Turns the results into a readable report. The language model only writes the summary, and a fixed template is used if the model is unavailable. It never makes the approval decision.
